# Build notes

- The project has four hash-routed views: Home, Login, Register, and Student Dashboard.
- It is plain HTML, CSS, and JavaScript. There is no bundler or install step.
- CSS creates the display platforms, floating shapes, and dimensional CampusCode marks. The dashboard mark rotates on its stage.
- Sign-in, registration, and event registration are local preview interactions. They do not contact a server.
- This implementation uses AI assistance and has not been measured against the Round 1 40% cap mentioned in the starter notes. Do not present it as compliant without checking the event rules and rewriting your own share of the work.
