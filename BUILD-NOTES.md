# Build notes

- The project has four hash-routed views: Home, Login, Register, and Student Dashboard.
- It uses plain HTML, CSS, and JavaScript with no bundler or install step.
- The UI follows CampusCode's live grid and editorial style, with black typography, purple and lime accents, and a blue hover state for COMPETE.
- CSS builds a dimensional brand stage on Home and the dashboard; the three-bar mark rotates above each platform.
- The forms and event registration are local preview interactions; there is no server or persistent account storage.
- This implementation uses AI assistance and has not been measured against the Round 1 40% cap mentioned in the starter notes. Do not present it as compliant without checking the event rules and rewriting your own share of the work.
